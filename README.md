# Weather App 🌦️

A responsive weather application built using the OpenWeather API that allows users to search any city and view real-time weather information instantly.

## Features 🚀
- Search weather by city name
- Real-time temperature updates
- Humidity, wind speed, and weather conditions
- Dynamic weather icons
- Responsive UI for mobile and desktop
- Error handling for invalid city names

## Tech Stack 💻
- HTML
- CSS
- JavaScript
- OpenWeather API

## API Used 🌍
OpenWeather API  
https://openweathermap.org/api

## Installation ⚙️

1. Clone the repository
```bash
git clone https://github.com/your-username/weather-app.git
```

2. Navigate to project folder
```bash
cd weather-app
```

3. Open `index.html` in browser

## API Setup 🔑

1. Create an account on OpenWeather
2. Generate your API key
3. Replace the API key in `script.js`

Example:
```javascript
const apiKey = "YOUR_API_KEY";
```
